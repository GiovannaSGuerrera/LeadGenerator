# Arquitetura resumida

Next.js + TypeScript fornece a interface local e a API de consulta. SQLite guarda os locais importados, as datas e as chaves de deduplicação. O script Overture consulta arquivos GeoParquet públicos via DuckDB, importa somente empresas com telefone, sem website informado e dentro dos 96 distritos oficiais. A tarefa do Windows verifica diariamente se há nova versão publicada. A Foursquare continua como fonte opcional quando houver uma exportação válida com telefone. `OverpassSourceAdapter` permanece desabilitado.

Os modos são separados por `mode` no domínio. As empresas reais ficam em `overture_places` ou `fsq_places`. Pedidos públicos vêm de `freelancer_requests`, alimentada pelo RSS oficial da Freelancer.com a cada hora, e de `pncp_requests`, alimentada pela API pública do PNCP diariamente quando disponível. A API une as fontes, filtra tipo, palavra-chave e recorte de idioma/moeda e ordena por publicação. O recorte Brasil usa `locale_tag = 'pt-BR'` somente quando há português e sinal explícito de Brasil/BRL; o recorte EUR exige orçamento anunciado em EUR. Cada resultado informa fonte e link original. O ID Overture pode ser pesquisado no Explorer para inspecionar o registro original. O telefone e a ausência de site são informações da fonte e requerem conferência manual.
